# LensKit Test Datasets

This directory contains datasets used to run LensKit's tests:

- `ml-latest-small` — a copy of the [MovieLens Latest Small](https://grouplens.org/datasets/movielens/) dataset, distributed in accordance with its distribution terms.
- `ml-100k` — a copy of the MovieLens 100K dataset, distributed by permission from GroupLens.  Do not further redistribute this data.
